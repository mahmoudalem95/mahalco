شروط الخدمة وسياسة الخصوصية وتحديد المسؤولية

آخر تحديث: سبتمبر 2026
إن استخدامك للموقع الإلكتروني، وواجهات API، وأي مخرجات ناتجة عن أي عملية حساب أو تحليل أو تخطيط أو أي مخرجات أخرى (ويُشار إليها مجتمعةً باسم «الخدمة» أو «المنتج») يخضع لقبولك الكامل للشروط الواردة أدناه. إذا كنت لا توافق على هذه الشروط، كليًا أو جزئيًا، فلا يجوز لك استخدام الخدمة بأي شكل من الأشكال.

1. إخلاء المسؤولية المهنية والحاجز القانوني

أ. المخرجات الأولية وغير النهائية

كل نتيجة أو حساب أو تحليل أو تقرير أو نموذج أو مخطط أو مقطع عرضي أو كود أو رسم بياني يتم إنتاجه من خلال الموقع الإلكتروني أو واجهة API (ويُشار إليه باسم «المخرج») هو مسودة، وأولي، ومواد مرجعية تقييمية بحتة.

ب. الشرط الإلزامي للاعتماد — موافقة خطية فقط

  • حظر الاستخدام أو التنفيذ: يُحظر حظرًا صارمًا استخدام المخرج في أي أعمال إنشائية، أو تقديمه إلى المحاكم أو الجهات الرسمية، أو إدماجه في مخططات نظامية، أو إصدار مناقصات، أو أعمال تصميم تفصيلي، أو أي اعتماد قانوني/هندسي آخر، ما لم يتم الحصول مسبقًا على موافقة رسمية وصريحة وخطية موقعة أو مرسلة مباشرة من عنوان البريد الإلكتروني المعتمد لمشغّل الخدمة: mahmoudalem95@icloud.com (ويُشار إليها باسم «الموافقة الرسمية»).
  • عدم المسؤولية في غياب الموافقة: في حال عدم وجود هذه الموافقة الرسمية الخطية، لا يتحمل مشغّل الخدمة ومالكوها ومطوروها (ويُشار إليهم باسم «المشغّل») أي مسؤولية، سواء كانت مباشرة أو غير مباشرة أو ناشئة عن المسؤولية التقصيرية أو العقد، عن أي ضرر أو خسارة أو عيب أو تكلفة أو مطالبة تنشأ عن أي استخدام للمخرج أو اعتماد عليه.

ج. المراجعة الإلزامية من مهندس مرخّص

أي حساب يستند إلى معايير، مثل HCM أو AASHTO أو HSM أو MUTCD أو المعايير الإسرائيلية، يتطلب المراجعة والتحقق والرقابة والحكم المهني المستقل من مهندس مرور/طرق/بنية تحتية مرخّص يحمل ترخيصًا ساريًا. ولا يشكّل المخرج بديلًا عن المشورة الهندسية المهنية والشخصية.

2. شروط استخدام الخدمة وواجهة API

  • الحساب ومفاتيح API: الوصول إلى واجهة API مشروط بالحصول على مفتاح API شخصي. يتحمل المستخدم وحده مسؤولية الحفاظ على سرية المفتاح، ويُمنع عليه نقله إلى أي طرف ثالث.
  • حدود المعدل وميزات الاشتراك: يخضع الاستخدام لحدود عدد الطلبات في الساعة (Rate Limits) وفقًا للخطة المشتراة (Trial، Developer، Practice، Enterprise). ويجوز للمشغّل حظر الوصول إلى أي حساب يتجاوز هذه الحدود أو ينخرط في استخدام مسيء.
  • الإلغاء واسترداد المبالغ: يمكن إلغاء الاشتراكات الشهرية في أي وقت عبر البريد الإلكتروني. يتم إصدار مفاتيح API يدويًا بعد الدفع والتأكيد.
  • التغييرات على الخدمة: يحتفظ المشغّل بالحق في تحديث أو تعديل أو إيقاف أو فرض قيود على أي أداة أو إجراء أو نقطة نهاية (endpoint) في واجهة API في أي وقت دون إشعار مسبق.

3. سياسة الخصوصية وجمع البيانات

أ. البيانات التي يتم جمعها

  • البيانات الشخصية: الاسم، وعنوان البريد الإلكتروني، ورقم الهاتف، وبيانات التعريف (مثل ملف تعريف GitHub) عند التسجيل، أو طلب مفتاح API، أو التواصل مع الخدمة.
  • بيانات الاستخدام والمدخلات الهندسية: البيانات التي يتم إرسالها إلى واجهة API، مثل أحجام المرور، وتوقيتات الإشارات، وهندسة التقاطعات/الطرق، وعنوان IP، وسجلات طلبات HTTP، وأوقات الاتصال.
  • بيانات الدفع: تتم معالجة المدفوعات بواسطة مزودي دفع خارجيين آمنين. ولا يخزّن المشغّل بيانات بطاقات الائتمان الكاملة على خوادمه.

ب. أغراض جمع البيانات

  • تقديم الخدمات، وإصدار مفاتيح API، وإدارة الاشتراكات.
  • مراقبة أداء الأنظمة، ومنع الاحتيال، وضمان أمن المعلومات.
  • تقديم الدعم الفني والرد على الاستفسارات.
  • تحسين تجربة المستخدم وتطوير أدوات هندسية جديدة، بما في ذلك تدريب وتحسين نماذج الذكاء الاصطناعي والخوارزميات المستخدمة في الخدمة.

ج. نقل البيانات إلى أطراف ثالثة

لن يقوم المشغّل ببيع أو تأجير أو نقل معلوماتك الشخصية إلى أطراف ثالثة، باستثناء الحالات التالية:

  • لاستمرار تشغيل الخدمة (مثل مزودي الخوادم والبنية التحتية السحابية ومعالجي المدفوعات).
  • بموجب أمر قضائي أو متطلب قانوني إلزامي.
  • في حال وجود نزاع أو دعوى قضائية أو إجراءات قانونية بين المستخدم والمشغّل.

د. أمن البيانات

يتخذ المشغّل إجراءات أمنية معقولة لحماية البيانات التي يتم جمعها، لكنه لا يستطيع ضمان حماية مطلقة من الاختراق غير المصرّح به أو الحوادث السيبرانية.
