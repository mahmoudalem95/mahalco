Freeway Facility Analysis

Planning-level HCM-style analysis of a freeway facility made up of basic, ramp merge, ramp diverge, and weaving segments. Edit the segment sequence, test operating conditions, and review bottlenecks, queue propagation, reliability, and improvement opportunities.

Facility, boundary, reliability, and calibration inputs

Weather and incidents reduce effective speed/capacity. Reliability uses a screening percentile multiplier, PTI = high-percentile time / free-flow time, BI = (high-percentile − typical) / typical, and TTI = typical / free-flow.

Facility segments

Rows are evaluated in order. Required fields include length, lanes, volume, speed, grade, trucks, and ramp fields; use Add segment to extend the facility.
