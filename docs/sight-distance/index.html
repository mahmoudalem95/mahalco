Sight Distance Calculation

Calculate stopping (SSD), passing (PSD), decision (DSD), intersection (ISD), and horizontal-curve sight distance using AASHTO Green Book Chapter 3 screening criteria. Grade, weather, pavement, lighting, and safety adjustments are reported with a combined recommendation. This dependency-free tool supports preliminary design; confirm current agency criteria for final plans.

PROJECT / DESIGN CONTEXT
STOPPING SIGHT DISTANCE (SSD)
Positive is upgrade; downgrade increases braking distance.

SSD = 1.47 × V × t + (1.47V)² / [2 × (a + 32.174 × grade)] where grade is decimal and positive for upgrade.

PASSING SIGHT DISTANCE (PSD)

PSD = d1 + d2 + d3 + d4; d4 is opposing-vehicle distance during the initial maneuver and passing time, multiplied by the safe-gap factor.

DECISION SIGHT DISTANCE (DSD)

DSD reports the maneuver-time table value and a physics check: 1.47 × V × t + V² / [30 × (a + grade)].

INTERSECTION SIGHT DISTANCE (ISD)

Signalized ISD uses crossing speed and clearance; unsignalized ISD uses major-road speed and gap acceptance, with vehicle length included.

HORIZONTAL CURVE / OBSTRUCTION

M = R[1 − cos(28.65 × SSD/R)] and SSDavailable = R arccos(1 − M/R) / 28.65.
