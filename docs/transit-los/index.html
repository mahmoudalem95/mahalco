Transit LOS (TLOS)

HCM Chapter 16 transit level of service calculator. Evaluate service, stop quality, access, vehicles, infrastructure, affordability, reliability, comfort, equity, and standards at a transit stop.

Scores use the API #9 convention: component scores range from 1 to 5, with 5 representing excellent performance. The weighted score is converted to an A-F grade. This is a planning-level stop assessment, not a substitute for an adopted agency standard.
