נפח נתיב קריטי

חישוב נפח קריטי בשלוש שיטות פאזה: זרועות מפוצלות, הפרדת שמאלה וטבעת כפולה.

הסבר מורחב: נוהל זה מאפשר לחשב את נפח התנועה הקריטי בנתיבים שונים בצומת, תוך התחשבות בהרכב התנועה, זמני רמזור וגיאומטריה. השיטה מתאימה לתכנון רמזורים והערכת קיבולת.

כלי ניתוח צמתים

ניתוח צומת מרומזר

עיכוב בקרה, אורך תור, יחס נפח-קיבולת ורמת שירות לכל זרוע ולצומת כולו.

HCM Ch. 19
הסבר מורחב: ניתוח מפורט של צמתים עם רמזורים, כולל חישוב עיכובים לפי שיטת HCM, אורכי תורים בתנאי עומס, וקביעת רמת שירות (LOS) לכל תנועה. משמש לתכנון ותפעול רמזורים.

ניתוח צומת לא מרומזר

בקרת עצור בשני כיוונים ובכל הכיוונים, עם קבלת מרווחים לפי תנועה.

HCM Ch. 20
הסבר מורחב: ניתוח צמתים ללא רמזורים (עצור או תנו זכות קדימה) המבוסס על קבלת מרווחים (gap acceptance). כולל חישוב קיבולת ועיכובים בתנאי תנועה משתנים.

ניתוח כיכר תנועה

קיבולת כניסה, יחס נפח-קיבולת, עיכוב בקרה ותור באחוזון 95 לכל זרוע.

HCM Ch. 22
הסבר מורחב: ניתוח ביצועי כיכרות תנועה לפי HCM, כולל קיבולת כניסה, עיכובים, אורכי תורים ורמת שירות. מתאים לתכנון כיכרות עירוניות ובין-עירוניות.

תיאום ותזמון רמזורים

ניתוח נתיבים ותורים

יחס נפח-קיבולת, עיכוב ותור באחוזון 95 לכל נתיב, מול אורך מפרץ הפנייה.

HCM Ch. 19 / 31
הסבר מורחב: ניתוח נתיבים בודדים בצומת, כולל חישוב עומסי תנועה, אורכי תורים בתנאי עומס, והשוואה לאורכי מפרצי הפנייה הקיימים. מסייע בקביעת מספר נתיבים נדרש.

ניתוח מקטע רחוב עירוני

ניתוח מסדרון עירוני

מהירות נסיעה ורמת שירות לאורך מסדרון שלם, על פני מקטעים רצופים.

HCM Ch. 17 / 18

רמת שירות להולכי רגל

הליכות לפי רוחב מדרכה, הפרדה מהתנועה ותנאי החצייה.

HCM Ch. 16

רמת שירות לרוכבי אופניים

נוחות רכיבה לפי מצב המיסעה, נפח התנועה ושיעור הרכב הכבד.

HCM Ch. 16
הסבר מורחב: ניתוח איכות הנסיעה לרוכבי אופניים בנתיבים ייעודיים או משותפים, תוך התחשבות במצב הכביש, נפח תנועה ושיעור משאיות.

רמת שירות לתחבורה ציבורית

HCM Ch. 16

רמת שירות רב-אמצעית

שילוב ציוני הולכי רגל, אופניים ותחבורה ציבורית לתוצאה אחת למסדרון.

פונקציות ביצועי בטיחות בצמתים

HSM

תכנון גיאומטרי של צומת עירוני

כבישים בין-עירוניים

רמת שירות לכלל המתקן על פני מקטעים בסיסיים, מקטעי שזירה ורמפות ברצף.

HCM Ch. 21
הסבר: ניתוח מתקן כביש מהיר שלם, הכולל שילוב של מקטעים, שזירות ורמפות, לקביעת LOS כולל.

HCM Ch. 24
הסבר: ניתוח מקטעי שזירה (Weaving) בהם תנועה מתערבת בין רמפות, חישוב קיבולת, מהירות ופרמטרי בטיחות.

רמת שירות במחלף

קיבולת מסופי הרמפות, תורים בקטע הפנימי והשפעה הדדית בין שני הצמתים.

HCM Ch. 23
הסבר: ניתוח ביצועי מחלף, כולל קיבולת מסופי הרמפות, תורים והשפעת הצמתים הסמוכים.

אמינות זמני נסיעה בכביש מהיר

תכנון עקומה אנכית

חתכים טיפוסיים בין-עירוניים

בחירת אמצעי בטיחות בשולי הדרך

AASHTO Roadside Design Guide

ניתוח סחיפה בגשרים

HEC-18 / AASHTO LRFD
הסבר: ניתוח פוטנציאל סחיפה (Scour) סביב גשרים, כולל סחיפה כללית, מקומית וסביב עמודים, לפי HEC-18.

ניתוח כלכלי ותועלת-עלות

AASHTO Red Book

ניתוח נתיבי תחבורה ציבורית

AASHTO / APTA

הערכת השפעה על הסביבה

FHWA / NEPA

תכנון חניונים

ITE / AASHTO

ניתוח צמתים רב-אמצעי

HCM Ch. 16 / 19
הסבר: ניתוח ביצועי צומת המשלבת מספר אמצעי תנועה – הולכי רגל, רוכבי אופניים, תחבורה ציבורית וכלי רכב פרטיים.

הנחיות בטיחות בתכנון

HSM / AASHTO

ניהול פרויקטים תחבורתיים

PMCM / AASHTO
הסבר: מתודולוגיות לניהול פרויקטי תשתית: תכנון, בקרת עלויות, לוחות זמנים, ניהול סיכונים ותקשורת.

תכנון תשתיות חכמות

FHWA / ITS

שאלות נפוצות (FAQ) – מהאלco

מהו ממשק API להנדסת תחבורה?

ממשק API (Application Programming Interface) להנדסת תחבורה מאפשר למפתחים ומהנדסים לשלב חישובי קיבולת, ניתוח צמתים, תכנון גיאומטרי ועוד, ישירות לתוך תוכנות או אתרים, ללא צורך בהרצה ידנית.

אילו תקנים מכוסים בקטלוג מהאלco?

הקטלוג כולל 51 נהלים המבוססים על HCM (Highway Capacity Manual), AASHTO Green Book, HSM (Highway Safety Manual), MUTCD, FHWA ותקנים ישראליים נוספים.

כיצד ניתן להשתמש ב-API של מהאלco?

ניתן לשלוח בקשות HTTP ל-https://api.mahalco.com/v1/calculate עם מפתח API (נרכש באתר) ונתוני הקלט. התשובה תכיל תוצאות מספריות, דוחות וגרפים.

האם ניתן לקבל גישת ניסיון ללא תשלום?

כן. אנו מציעים מפתח ניסיון לשבועיים עם 30 בקשות לשעה. פשוט שלחו מייל לכתובת המופיעה בתחתית העמוד.

למי מיועד הקטלוג?

למהנדסי תנועה, מתכנני כבישים, חברות ייעוץ, רשויות מקומיות, סטודנטים וחוקרים – כל מי שעוסק בתכנון תחבורה ותשתיות.
